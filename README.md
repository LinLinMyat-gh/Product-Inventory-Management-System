### ASP.NET MVC | SQLite | CRUD System



## 📌 About This Project

This is a **modern Product Inventory Management System** built using **ASP.NET MVC** with **SQLite database integration**.

The system is designed to efficiently manage product data through a clean, responsive, and user-friendly interface, supporting full CRUD functionality and real-time product tracking.

It demonstrates practical implementation of **web development principles, database management, and MVC architecture**.



## 🚀 Project Overview

The system allows users to:

- Add new products to inventory  
- View detailed product listings  
- Update existing product information  
- Delete products from the system  
- Upload and manage product images  
- View dynamic inventory statistics through a dashboard  



## ✨ Features Implemented

- CRUD Operations (Create, Read, Update, Delete)
- Product Image Upload System
- Responsive UI Design (Mobile-Friendly)
- Pagination System for Product Listings
- SQLite Database Integration
- Dynamic Dashboard Statistics
- Bootstrap 5 Styled Modern UI
- ASP.NET MVC Architecture



## 🛠️ Technologies Used

### Frontend
- HTML5  
- CSS3  
- Bootstrap 5  

### Backend
- ASP.NET MVC  
- C#  

### Database
- SQLite  
- Entity Framework
